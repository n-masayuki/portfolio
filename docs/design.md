## Typography

- Heading: ページ・セクションの階層が分かるサイズ、太さ、行間を設定する
- Body: 本文として読みやすいサイズと行間を設定する
- Caption: 補足情報にのみ使用し、本文より小さくする
- 英字の装飾には `Grape Nuts`、作品プレースホルダーには `Montserrat` を使用する
- Webフォントはセルフホストし、必要なウェイトだけを読み込む
- フォントサイズ、行間、ウェイトはCSS Custom Propertiesでトークン化する
- 見出しレベルと文字サイズの序列を一致させる

## Spacing

- 基本単位: 4px / 8px
- 余白は4px刻みを基本とし、セクション間には一貫した大きめの余白を使う
- コンポーネント内部の余白とコンポーネント間の余白を混同しない

## Color

- 背景、本文、補助テキスト、罫線、アクセント、状態色をCSS Custom Propertiesで定義する
- 本文と背景のコントラストを確保する
- 色だけで状態や意味を伝えない
- hover、focus-visible、disabledなどの状態色をコンポーネントごとに定義する

## Components

### Icons

- UI操作用アイコンはLucideを基本とする
- Menu、Close、Plus、外部リンクなど、操作の意味を補助する目的で使用する
- アイコン単体の操作要素には、テキストまたは適切な `aria-label` を設定する
- 装飾目的のアイコンは `aria-hidden="true"` とする
- GitHubなどのブランドロゴは、Lucideに無理に置き換えず、既存SVGなどを使用する

### Header

- 全ページ共通のグローバルナビゲーションを提供する
- モバイルでは操作しやすいナビゲーションへ切り替える
- 現在地を視覚的かつ支援技術にも分かる形で示す

### Footer

- 著作権表記と必要なナビゲーションを配置する
- 連絡先など公開対象外の情報は掲載しない

### Button

- 主操作と副操作を視覚的に区別する
- hover、focus-visible、disabledの状態を持たせる
- アイコンのみのボタンにはアクセシブルな名前を設定する

### Contact Form

- 入力内容の上限をHTMLの `maxlength` で制御する
- お問い合わせ内容は入力中の文字数を表示する
- 文字数表示領域の高さを確保し、入力開始時のレイアウトシフトを避ける

### Tag

- 技術やカテゴリなど、短い属性情報の表示に使用する
- 操作を伴わない表示用タグと、フィルター用の操作要素を区別する

### WorkCard

- 作品一覧でタイトル、概要、使用技術、詳細への導線を一貫した順序で表示する
- カード全体をリンクにする場合、内部に入れ子の操作要素を置かない

### Modal

- 開閉時のフォーカス管理、Escapeキーによる閉じる操作、背景へのスクロール抑止を実装する
- モーダルを閉じた後は、開いた要素へフォーカスを戻す

## Animation

- 基本的なtransitionはCSSで実装する
- 複雑なアニメーションのみGSAPを使用する
- 動きは内容理解を妨げず、操作結果のフィードバックを補助する目的に限定する
- `prefers-reduced-motion: reduce` では非必須の動きや自動再生を抑制する
