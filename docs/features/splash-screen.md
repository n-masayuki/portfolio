# スプラッシュスクリーン

## 目的

ポートフォリオの第一印象として、NM のロゴとサイト共通の淡いグラデーションを見せる。
採用理由は雰囲気づくりであり、ロード状況の表示やパフォーマンス改善ではない。
本文を閲覧できるまでに約2秒の演出が入るため、訪問者の操作と再訪時の使いやすさを優先する。

## 有効・無効の切り替え

`src/pages/index.astro` の `enableSplash` で切り替える。Lighthouse の比較測定など、一時的に演出を外したい場合もこの設定を使う。

```astro
const enableSplash = false;
```

- `false`: 無効。スプラッシュの HTML と `/scripts/splash.js` の読み込みタグを出力しない。
- `true`: 有効。以下の表示ルールに従って再生する。

公開サイトに反映するには、設定変更後に `npm run build` を実行し、生成された `dist` をアップロードする。
この設定はスプラッシュのみを切り替える。本文や見出しの GSAP アニメーションは別の処理として動作する。

## このプロジェクトの表示ルール（有効時）

- 対象はトップページ `/` のみ。制作実績・404・サンクスページでは表示しない。
- 「初回」は同じタブのページセッション内で最初の表示とする。`sessionStorage` の `portfolio:splash-seen` で管理する。
- 再読み込み、詳細ページからの帰還、ブラウザの戻る操作では繰り返さない。
- 新しい独立したタブでは再表示できる。タブの複製・復元ではブラウザがセッション情報を引き継ぐ場合がある。
- `/#contact` など、ハッシュ付きのアクセスでは目的のセクションへの移動を優先して省略する。
- `prefers-reduced-motion: reduce`、バックグラウンドでの初期読み込み、ストレージ利用不可の場合も省略する。省略時は表示済みとして記録しない。
- 再生開始時に表示済みを記録し、途中でスキップしても再表示しない。

## 演出と操作

- NM と Portfolio を中央に配置する。新しい画像やライブラリは追加しない。
- 登場は約0.7秒、余韻を含め開始から1.6秒でフェードアウトを始め、合計約2秒で閉じる。
- 読み込み率や架空の進捗は表示しない。画像・フォント・React・Turnstile の準備を待たない。
- スキップボタンは設けず、約2秒で自動終了する。Escape でも即座に終了できる。
- 表示中はネイティブのモーダル `dialog` を使い、背後へのクリック・フォーカス移動を防ぐ。スクロールも一時停止する。
- 終了時はモーダルを閉じ、背後の操作とスクロールを戻す。本文へ強制スクロールしない。
- 再生途中の動きの設定変更、別タブへの切り替え、ページ離脱、ハッシュ変更でも終了する。

## 実装方針

- `src/components/Home/Splash.astro` にマークアップと CSS を置く。
- トップページから Layout の `splash` スロットへ渡し、サイト本文の前に配置する。
- `public/scripts/splash.js` は同一オリジンの小さな外部スクリプトとして同期実行する。本文の解析前に表示判定するため、スクリプト取得の通信が1回増える。
- Astro の `is:inline` はこの外部スクリプトを加工せず出力する指定。インライン JavaScript 本体は追加せず、既存の CSP を維持する。
- HTML の初期状態では dialog を閉じておく。JavaScript 無効・取得失敗の場合は通常の本文を表示する。
- CSS のアニメーション終了と2秒タイマーの両方で終了を保証する。タイマーはブラウザの実行状況により遅れる場合がある。
- 終了時はタイマーとイベントリスナーを解除する。追加の React・GSAP 処理は不要。
- 時間や表示条件を変更するときは、この文書と実装を併せて更新する。

## 確認項目

- `enableSplash = false` でスプラッシュが表示されず、`/scripts/splash.js` の読み込みが発生しない。
- 以下の表示・操作の確認は `enableSplash = true` で行う。
- 初回の `/` で表示され、約2秒後に閉じて本文が操作できる。
- ボタンなしでも表示され、Escape で即座に閉じる。Tab で背後のリンクへ移動しない。
- 再読み込み、詳細ページから戻る操作では再表示されない。
- ハッシュ付き URL、下層ページ、動きを減らす設定では省略される。
- ストレージ利用不可・JavaScript 無効時にも本文を閲覧できる。
- 表示中にタブを離れたり動きの設定を変更しても、操作不能な画面が残らない。
- スマートフォンの縦横表示でロゴが収まる。

再確認するときは `enableSplash = true` が反映されていることを確認し、開発者ツールの Console で `sessionStorage.removeItem('portfolio:splash-seen')` を実行して、ハッシュのない `/` を再読み込みする。有効・無効の切り替えだけでは、同じタブに残っている表示済みの記録は消えない。
