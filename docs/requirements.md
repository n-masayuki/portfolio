# 要件

この文書は期待する挙動を扱います。現在の構成は [アーキテクチャ](architecture.md) を参照してください。

## Purpose

ポートフォリオ。
フロントエンドだけを過度にアピールするのではなく、
Web制作・設計・改善・AI活用を含めた実務能力を示す。

## Target

・Web制作会社
・事業会社
・フロントエンドエンジニア
・マークアップエンジニア
・Web制作を含むエンジニア職

## Pages

```tree
Home
├─ Hero
├─ About
├─ Skills
├─ Selected Works
├─ GitHub
└─ Contact

Detail Pages
└─ /works/[slug]
   └─ 詳細説明が必要な代表案件のみ
```

## Contact

- お問い合わせフォームから名前、メールアドレス、問い合わせ内容を送信できる
- 名前は24文字以内、メールアドレスは254文字以内、問い合わせ内容は500文字以内とする
- 問い合わせ内容の入力中に現在の文字数を表示する
- フォーム送信はFormspreeを利用する
- Bot対策としてCloudflare Turnstileを利用する

## Privacy

・氏名非公開
・顔写真非公開
・メールアドレス非公開
・クライアント実名非公開
・機密情報非掲載
